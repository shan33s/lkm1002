程式用途：
這是一段用 Python 編寫的聚餐費用分攤與預算檢核計算器。它的主要功能包括：
字串清理：自動去除聚餐名稱的多餘空白並轉為小寫，並將帶有貨幣符號與逗號的餐費字串（如 " NT$1,200 "）轉換為數值型別 (float)。
費用計算：自動計算 10% 的服務費、減去折價券優惠，得出應付總額，並根據分攤人數計算每人平均費用。
預算比對：將每人實際分攤金額與預設的個人預算進行比較，自動判定是否超出預算 (is_over_budget)。

三組測試的實際結果摘要以下為三組測試情境的實際計算結果摘要（基準餐費皆為 1200 元，10% 服務費，個人預算 300 元）：
測試案例分攤人數折價券金額應付總額每人平均費用是否超過預算？
測試一4 人100 元1,220 元305.00 元是 (True)
測試二5 人100 元1,220 元244.00 元否 (False)
測試三4 人220 元1,100 元275.00 元否 (False)
結果解析：
測試一因人數較少且折扣較小，每人分攤 305 元，微幅超過 300 元預算。
測試二透過增加分攤人數（5人），成功將每人費用降至 244 元，符合預算。
測試三透過提高折價券面額至 220 元，降低總額後也成功將每人費用控制在 275 元，符合預算。
